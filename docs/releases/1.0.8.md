# Projecto 1.0.8

Projecto 1.0.8 refreshes the desktop identity throughout the packaged app and
Squirrel.Windows release.

- Adds a high-resolution Projecto app icon for Linux and other PNG consumers.
- Adds a multi-size Windows icon for the executable and Squirrel installer.
- Adds a macOS icon bundle for future signed and notarized builds.
- Uses the branded icon for native app windows and taskbar entries.
- Keeps the Projecto website favicon visually identical to the desktop app.
