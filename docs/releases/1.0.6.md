# Projecto 1.0.6

Projecto 1.0.6 is the Squirrel.Windows release for the redesigned desktop
interface.

## Highlights

- Introduces the concrete, ink, and lime Projecto visual system.
- Adds Inter Tight typography and compact responsive window layouts.
- Adds scoped GSAP route, heading, section, toggle, and rolling-label motion.
- Adds reduced-motion behavior and stronger keyboard focus treatment.
- Preserves the existing project import, launch, terminal, update, billing,
  preload, and IPC contracts.

## Windows release assets

Build with `npm run make`. Publish these three files from
`out/make/squirrel.windows/x64` together:

- `Projecto-1.0.6.Setup.exe`
- `projecto-1.0.6-full.nupkg`
- `RELEASES`

After upload, update the desktop release metadata in `D:\projecto_frontend`
so the update API returns version `1.0.6`, the setup URL, SHA-256 digest, file
size, and Squirrel feed URL.
