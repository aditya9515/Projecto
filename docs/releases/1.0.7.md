# Projecto 1.0.7

Projecto 1.0.7 adds safe, versioned desktop storage maintenance to the
Squirrel.Windows release.

## Highlights

- Runs an allowlisted cleanup once on the first normal launch of each version.
- Adds a Storage & cleanup settings panel with a live preview, confirmation,
  cleanup summary, and last-run report.
- Removes UUID-named run logs and helper scripts after 30 days or when retained
  run artifacts exceed 250 MB.
- Clears Electron HTTP and compiled-code caches without deleting cookies,
  sessions, local storage, or credentials.
- Removes stale atomic-write leftovers older than 24 hours.
- Deletes legacy `projects.json` only after every record is verified in the
  current `project-details.json` store.
- Protects imported project folders, settings, approvals, subscriptions,
  active run process markers, and corrupt-data backups.
